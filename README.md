Pré-requisitos
Certifique-se de ter o Python 3 instalado no computador antes de iniciar.

Download do Projeto
Aceda ao link do repositório no GitHub, clique no botão "Code" e selecione "Download ZIP", extraindo a pasta de seguida.

Instalação de Dependências
Abra o terminal (ou prompt de comando), navegue até à pasta extraída do projeto e instale a framework Flask executando o comando: pip install flask.

Execução do Servidor
No mesmo terminal, inicie a aplicação executando o comando: python app.py.

Acesso à Plataforma
Abra o navegador web e aceda ao endereço http://localhost:5000 (ou o endereço IP que surgir no terminal) para testar o sistema e interagir com as funcionalidades.
